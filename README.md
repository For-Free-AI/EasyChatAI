# EasyChatAI

这是一款**轻量 Android AI 对话客户端**。填入你自己的 API 即可对话，**无需注册账号**；数据仅存本机，不上传、不追踪。

> **v2.1.1** · Flutter 3.44.9 / Dart 3.12 · 仅 Android

## 是什么

- **自带 Key**：支持 OpenAI Chat Completions 与 Anthropic Messages 两大类兼容 API ，内置 Agnes / DeepSeek / OpenAI / Anthropic 的BaseURL预设，也可完全自定义。
- **隐私优先**：配置、对话、附件、图片全部存于本机（`shared_preferences` + `sqflite`），卸载即清除。
- **功能齐全**：流式输出、深度思考、联网搜索、多模态图片、文档附件、Markdown 高亮、多 API 档案、会话管理与备份。

---


**首次使用**：安装后进入设置 → 选「连接提供商」→ 填 Base URL 与 API Key → 测试连接拉取模型 → 检查通过即可对话。

**发图 / 传文档**：输入框为空时点右侧黑色「+」→ 拍照 / 图片 / 文件；图片可裁剪，文档本地解析为纯文本，均不上传。

## 兼容性

| 项目 | 说明 |
|---|---|
| 系统 | 最低Android 7.1（API 24），目标 Android 16 |
| 架构 | **ARM64位架构**（大多数安卓设备） |
| 屏幕 | 手机 / 平板自适应，深浅色 + OLED 纯黑 |

> v2.0.0 起只提供 arm64 包，不再提供 arm32 / x86；其他架构请用源码自行构建。（需 Flutter 3.44.9+、Android SDK、JDK 17）

## 功能特性

**对话**：双协议流式输出（SSE）、深度思考链、联网搜索（模型自主判断）、自动命名、Token 用量、角色预设、多 API 配置档案、采样参数（全局 + 会话两级）、重新生成 / 编辑重发。

**多模态与附件**：拍照 / 相册多图（≤9）裁剪后发送；DeepSeek 端到端看图，其他提供商走可配置的独立视觉 API；TXT / MD / DOCX 本地解析成纯文本随消息发送，超长自动截断。

**阅读与交互**：Markdown 全渲染、180+ 语言代码高亮与一键复制、气泡内跨段拖选 + 大面板复制、生成时视口静止、全中文文案。

**数据与界面**：SQLite + SP 本地存储、会话搜索 / 批量删除 / 重命名、JSON 备份导出导入（系统文件管理器自选位置）、Material 3、DeepSeek 式侧边栏。

Flutter 3.44.9（Impeller）· Dart 3.12 · Provider 6.x · http（SSE 流式，UTF-8 防乱码）· shared_preferences + sqflite（Repository 双读）· flutter_markdown + flutter_highlight · file_picker / docx_to_text / image_picker / image_cropper · Gradle 8.14 / AGP 8.11.1 / Kotlin 2.2.20。
